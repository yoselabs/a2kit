## REMOVED Requirements

### Requirement: The REST surface is a mounted ASGI sub-application

**Reason**: The minimal REST stub at `a2kit.packages.rest.build_rest_app` is replaced by a real FastAPI sub-app at `a2kit.packages.http.build_http_app`. The new capability is covered by `http-surface`; this old capability is fully superseded.

**Migration**: Replace `from a2kit.packages.rest import build_rest_app` with `from a2kit.packages.http import build_http_app`. The new function accepts an `AppRuntime` (not an `App`) and returns a `fastapi.FastAPI` instance (not a Starlette app). The multiplex finisher is unchanged for callers — they continue to invoke `build_parent_app(app)` which uses the new function internally.

### Requirement: The REST surface serves a health route and an OpenAPI document

**Reason**: Health and OpenAPI are still served, but their provenance changes: OpenAPI is now auto-generated by FastAPI from the registered tool routes (no longer a stub with empty `paths`); health remains at `/api/health` and is now a default FastAPI route registered by `build_http_app`. The new behaviour is captured in the `http-surface` capability.

**Migration**: Consumers reading `/api/openapi.json` will now see full per-tool route definitions instead of an empty `paths` object — this is additive and backwards-compatible for consumers that only used `info`. Consumers that depended on the empty `paths` (treating its presence as a sentinel) must update.
